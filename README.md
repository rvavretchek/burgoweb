# burgoweb
Sistema de Gestão de Condomínio

## Validação PostgreSQL

Use `npm run test:integration`. O comando seleciona automaticamente o PostgreSQL 18 local no Windows, uma URL externa configurada ou Testcontainers. Consulte `docs/operations/postgresql-integration.md`; uma execução em que todos os testes aparecem como `skipped` não satisfaz o gate de integração.
